# 상품 추가 (쿠팡 파트너스 링크 생성)

기준: 2026-10-18 sabol.kka 상품 12개를 실제로 넣은 과정. 상품 파일은 계정마다 따로다 (`accounts/<계정>/data/products.csv`, 기본 계정은 `data/products.csv`). 소개 글은 이 목록을 날짜로 돌려 쓰므로, 컨셉에 안 맞는 상품이 섞이면 그것도 나간다.

## 0. 할 수 있는 환경인지 먼저 확인
- 링크는 **사용자 Chrome 의 쿠팡 파트너스 로그인 세션**으로만 만든다 (파트너스 API 는 최종 승인 전이라 못 씀). `chrome-browser` 스킬을 먼저 읽고 Claude in Chrome 도구(`mcp__claude-in-chrome__*`)를 불러온다.
- 브라우저 도구가 없으면 (클라우드 세션 등): 링크를 지어내지 않는다. 고를 상품 종류·검색어 목록만 만들어 주고, "데스크톱 앱에서 Chrome 을 연결한 세션으로 다시 요청하거나, 링크를 직접 만들어 `물건 | 상품명 | https://link.coupang.com/a/...` 형식으로 보내 달라"고 안내한다.
- 로그인이 안 돼 있으면 사용자에게 로그인을 부탁하고 기다린다. 비밀번호를 대신 입력하지 않는다.

## 1. 몇 개, 무엇을 고를지
- **개수:** 요청한 만큼. 정해지지 않았으면 하루 링크 글 수 × 10일 분량(하루 2개면 20개)이 될 때까지. `ops_advice` 의 보충 알림 기준도 10일이다.
- **먼저 읽을 것:** 지금 `products.csv`(중복 방지), 계정 `config.yaml` 의 `talk_topics`·컨셉 주석, 다른 계정의 `products.csv`(같은 상품 금지).
- **고르는 기준:**
  - 계정 컨셉 안의 물건만 (sabol.kka: 살림·주방·생활가전·신기한 꿀템. 상품 정리 커밋 `b3014e9` 이후 반려동물·식품 상품은 넣지 않는다)
  - **이미 가진 사람이 많고 의견이 갈리는 물건.** 지금까지 가장 반응이 좋았던 글은 "주방 저울 있는 사람 솔직히 말해줘"(조회 449, 답글 21)와 "정수기 쓰는 사람 솔직히 말해봐"였다. `talk_topics` 에 있는 물건이면 더 좋다
  - 후기 많은 대표 상품, **5만~50만 원대**. 3만 원 미만은 수수료가 작아 빼고, 건강·의료·식품·유아용은 뺀다
  - 상품명에 **고를 때 기준이 되는 사실**(인원, 용량, 방식, 크기)이 있으면 좋다. 소개 글의 "고를 때 볼 점" 줄이 이 사실만 쓴다
  - 시즌이면 시즌 물건을 조금 섞는다 (겨울: 가습기·제습기 등). 단 난방·전열 기구는 안전 표현 때문에 글이 막히기 쉬우니 피한다

## 2. 채널 아이디 (계정별 통계, 2026-10-31)
쿠팡 파트너스 리포트는 링크를 만들 때 고른 **채널 아이디**로만 나눠 볼 수 있다. 채널 없이 만든 링크는 리포트의 "기본값"으로 모인다.
- 계정 ↔ 채널: `sabolkka` → `sabolkka`, `openbrain` → `openbrain7777`. 새 계정은 계정 이름과 같은 채널을 쓴다.
- 링크를 만들기 전에 파트너스 → 내 정보(또는 추가 기능) → **채널 아이디 관리**에서 그 채널이 있는지 본다. 없으면 만들지 말고 사용자에게 "채널 아이디 생성에서 `<채널>` 을 만들어 달라"고 부탁한 뒤 기다린다.
- 링크를 생성할 때 채널 선택란에서 그 계정의 채널을 고른다. 기본값(채널 없음)으로 만들지 않는다.
- 확인: 만든 링크 하나를 열어 이동한 주소의 `subid=` 값이 채널 이름인지 본다 (비어 있으면 채널 없이 만든 것). 링크 서버 주소가 막힌 환경이면 사용자에게 열어 봐 달라고 한다.
- **다른 계정의 링크를 복사해 쓰지 않는다.** 상품이 같아도 계정마다 자기 채널로 다시 만든다. 시즌 모음(`bundles.yaml`)의 검색 결과 링크도 같다 (2026-10-31 확인: sabolkka 의 모음 링크 8개와 조명 상품 3개가 openbrain 링크를 그대로 써서 두 계정 클릭이 섞였다).
- 2026-10-31 이전에 만든 sabolkka 링크는 채널 없이(기본값) 만들어졌다. 다시 만들 때 위 규칙대로 바꾼다.

## 3. 링크 만들기 (Chrome)
1. `https://partners.coupang.com/#affiliate/ws/link/0/<검색어>` 로 검색한다 (검색어는 URL 인코딩).
2. 기준에 맞는 상품을 고르고, **채널 아이디를 그 계정의 채널로 고른 뒤** 링크 생성 버튼(`.btn-generate-link`)을 누른다.
3. 페이지에 나타난 `https://link.coupang.com/a/...` 와 상품명, 가격대(승인용으로만, 파일에는 안 씀)를 읽는다.
4. 여러 개를 한 번에 돌릴 때: **JS 반복문은 비동기로 시작하고 결과를 폴링**한다 (한 번의 JS 실행은 45초 제한). 반복문을 겹쳐 실행하면 결과가 섞이니, 하나가 끝난 뒤 다음을 시작한다.
5. 같은 상품에 링크를 두 번 만들지 않는다.

## 5. products.csv 에 추가
- 머리글: `product_id,name,category,power_w,default_hours,link,note` (선택 칸 `experience` 는 사용자 본인이 쓴 경험 메모가 있을 때만)
- `product_id`: 계정 접두어 + 다음 번호 (sabol.kka 는 `s13`, `s14`, …). 기존 번호와 겹치면 로드가 실패한다
- `name`: 쿠팡 상품명 그대로 (쉼표가 있으면 큰따옴표로 감싼다)
- `category`: 소개 글용은 `living`, `kitchen`, `light`, `pet` 중 하나 (그 밖은 `products.py` 의 `CATEGORIES`)
- `power_w`, `default_hours`: 비워 둔다 (전기요금 계산 글 전용)
- `link`: `https://link.coupang.com/...` 또는 `https://coupa.ng/...` 만 통과한다
- `note`: 120자 이내 1~2줄. **상품명·상세 페이지에 적힌 사실만** (용량, 인원, 방식, 색상). 아래는 코드가 거부한다:
  - 후기·리뷰·별점·"써보니"·"우리 집" 같은 표현
  - 안전·화재·무해·전자파·숙면·건강·"걱정 없"·"아이 방"
  - 가격·할인·순위는 코드가 막지는 않지만 쓰지 않는다 (금지어라 글이 보류된다)

python -m pytest -q

- main 에 합쳐진 다음 생성(20:00 KST)부터 소개 글에 쓰인다.

## 함정
- 링크를 지어내거나 다른 사람·다른 계정의 링크를 쓰지 않는다. 수익이 안 잡히고, 가짜 링크는 발행 직전 링크 검사에서 글이 보류된다.
- 상품 상세 페이지 문구나 후기를 `note` 에 그대로 옮기지 않는다 (규칙 2). 사실만 짧게 다시 쓴다.
- 품절·판매 종료 상품은 링크가 살아 있어도 빼고 같은 종류의 다른 상품을 고른다.
